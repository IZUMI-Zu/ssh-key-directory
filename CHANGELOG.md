### Added

- Config-as-code identities, aliases, and validated OpenSSH public keys.
- Configurable identity groups with aliases, deduplicated aggregate key endpoints, and type filtering.
- Plain-text, JSON, fingerprint, health, and directory endpoints.
- Key-type abbreviations, aliases, and optional type filtering.
- Responsive light and dark interface built with UnoCSS.
- Worker route tests and automated Antfu UI pre-flight checks.
